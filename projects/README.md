# Projects

One folder per song:

```
projects/<slug>/
  README.md    the brief: topic, audience, angle, decisions, Status line, Takes
  SOURCES.md   a row per factual claim a joke rests on, with an honest status
  song.md      the lyric sheet
```

**Lyrics are committed**, unlike the audiobook sibling's manuscripts, because
cloud sessions have to see them to keep working. **This repo is public**, so
a song's lyrics are public from the first commit, before it is released. That
is fine for a comedy song meant to spread. If a song ever needs to stay
unreleased until launch, make the repo private first; do not move its lyrics
to a git-ignored folder, because cloud sessions would lose them.

Audio never goes in here. See the `Takes` table in each README.
