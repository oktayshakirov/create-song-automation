# Sourcing jokes

A song about a real product makes factual claims, and the funny version of a
fact is always the more dramatic one. The audiobook sibling audited thirteen
claims after drafting and found seven overstated, all in the dramatic
direction. Comedy pulls the same way, harder.

## The line between a joke and a false claim

- **Hyperbole about a feeling is fine**: "I hit my limit before I said
  hello." Nobody believes it literally.
- **A number, date, name or quote is a claim**: "a single prompt took me from
  twenty-one to a hundred" needs a source, and the source has to say a
  *single user reported* it, not that it happens to everyone.
- **Attributing intent is a claim**: "they throttle you on purpose" is an
  accusation. Joke about the experience, not about motives you cannot source.
- **Never invent a quote** from a real person or company.

## SOURCES.md

One row per claim, before the lyric is written:

| # | Claim | Source | Status | Used in |
|---|---|---|---|---|

Status means exactly one of:

- **verified**: someone read the primary source (the company's own page, the
  original post)
- **reported**: read in a news article that reports it
- **snippet**: seen only in a search result summary, not read. It is not
  usable in a lyric until it is upgraded
- **memory**: someone believes it but no one has checked. It is not usable
  either

Upgrading a status means reading the source. Do not upgrade one you did not
read.
